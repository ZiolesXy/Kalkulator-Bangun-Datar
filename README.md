# Geometry Calculator & Quiz

Aplikasi CLI menggunakan Python untuk menghitung bangun datar
dan mengerjakan quiz bangun ruang.

## Fitur

1. Kalkulator 7 bangun datar.
2. Quiz 5 bangun Datar(coming soon).
3. Tingkat kesulitan Easy, Medium, dan Hard.
4. Jumlah soal dapat ditentukan pengguna.
5. Pemeriksaan jawaban otomatis.
6. Penyimpanan hasil quiz dalam CSV menggunakan Pandas.

## Teknologi

- Python
- Pandas
- CSV
- Random
- Math
- Datetime

## Instalasi

Jalankan perintah berikut di terminal:

```powershell
py -m pip install pandas
```

## Menjalankan aplikasi

```powershell
py main.py
```
