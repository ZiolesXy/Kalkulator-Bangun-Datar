# Geometry Calculator

Aplikasi CLI menggunakan Python untuk menghitung luas dan keliling
bangun datar, serta luas permukaan dan volume bangun ruang.

## Fitur

1. Kalkulator 7 bangun datar (persegi, persegi panjang, segitiga, lingkaran, jajar genjang, trapesium, belah ketupat).
2. Kalkulator 8 bangun ruang (kubus, balok, tabung, kerucut, bola, prisma segitiga, limas segitiga, limas segiempat).
3. Validasi input angka (menolak input bukan angka, negatif, dan nol).
4. Pemeriksaan kelayakan sisi segitiga (triangle inequality).
5. Penyimpanan riwayat perhitungan ke Excel menggunakan Pandas.

## Teknologi

- Python
- Pandas
- Openpyxl
- Math

## Instalasi

Jalankan perintah berikut di terminal:

```powershell
py -m pip install pandas openpyxl
```

## Menjalankan aplikasi

```powershell
py main.py
```
